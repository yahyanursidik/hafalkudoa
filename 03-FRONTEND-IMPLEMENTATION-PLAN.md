# Frontend Implementation Plan

## F0 — Foundation
React + TS, Refine Core 5, routing, auth shell, tokens, responsive shell, test setup.

## F1 — Static Prototype
Gunakan 5 fixture doa lokal. Buat Home, Doa list, Detail, Learning screen, reading-level switch, arti toggle, source display, dan color chunks. Tanpa API.

## F2 — Hafalan Interaction
Tambahkan hide/reveal, progressive hiding, hint, recall state, self-assessment.

## F3 — Backend Integration
Hubungkan `/api/v1/dua`, detail, categories/tags, child profile, preferences, progress.

## F4 — Murajaah
Due list, review screen, complete review, next item.

## F5 — Parent Area
Children, progress, target, reading level, content selection.

## F6 — Polish
320px mobile, RTL, large Arabic, accessibility, slow network, error states.

## Acceptance Global
- Arabic selalu tersedia
- source selalu tersedia
- arti berasal dari API/internal imported content
- tidak ada audio
- tidak ada Latin-only
- tidak ada generic SaaS UI
