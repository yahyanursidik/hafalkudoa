# Anti-Slop UI — Doa & Dzikir Anak

## Principle
Every element must earn its place.

UI hanya boleh membantu orientation, reading, memorization, feedback, progress, atau source/context.

## Avoid
- card proliferation
- generic SaaS dashboard
- decorative arch
- mosque
- crescent
- star
- lantern
- tasbih
- decorative calligraphy
- random Islamic pattern
- excessive gradient
- glassmorphism
- meaningless badge
- decorative status dot
- filler illustration
- filler copy
- confetti

## Child-Friendly != Childish
Gunakan large controls, simple language, whitespace, calm color, clear grouping. Tidak perlu mascot/cartoon.

## Source Must Not Be Removed
Anti-slop tidak boleh menjadi alasan menghilangkan provenance. Setiap doa harus memiliki akses ke sumber.

## Delivery Gate
- Arabic jelas
- Latin sesuai reading level
- translation toggle bekerja
- source accessible
- no audio controls
- no filler decoration
- primary action jelas
- 320px works
- no horizontal overflow
- RTL correct
- color is not sole cue
